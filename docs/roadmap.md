# (계속) 👤 두세 달에 한 번 보관 파일 내려받기 · 5분

**돈을 안 쓰는 대신 생긴 유일한 숙제입니다.**

GitHub 보관은 **90일이 지나면 파일을 지웁니다** (최대값이 90일입니다).
R2 였다면 영구 보관이라 이 숙제가 없었을 텐데, 카드 등록을 안 하는 쪽을
고르셨으니 이건 사람이 해야 합니다.

**잊어버리셔도 됩니다 — 메일이 갑니다.**

매주 금요일 아침에 자동으로 확인해서, 30일 밑으로 남았는데 아직 안
받으셨으면 **[보관 파일 만료 알림] 작업이 일부러 실패합니다.**
GitHub 이 실패 메일을 보내주기 때문입니다.

> ⚠️ 이 작업에 빨간 X 가 떠도 **고장난 게 아닙니다.**
> "파일 받아 두세요" 라는 뜻이고, 메일 안에 내려받을 주소가 들어 있습니다.

**받은 뒤 알림 끄기** (안 하면 매주 옵니다)

1. GitHub → **Actions** → **보관 파일 만료 알림** → **Run workflow**
2. `내려받아 저장을 마쳤습니다` 를 **true** 로 바꾸고 **Run workflow**

자세한 것은 [`docs/archive-setup.md`](archive-setup.md) 에 있습니다.
