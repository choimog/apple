**대표님이 하실 일: 약 3분.**

> 켜지 않으셔도 순위표·그래프·엑셀은 전부 그대로 됩니다.

## 가) 얼마나 드나요? — 먼저 이것부터

| | 처음 계산값 | **실측 (2026-08-09)** |
|---|---|---|
| 한 번 부를 때 | 약 110원 | **약 52원** |
| 한 달(31일) | 약 3,400원 | **약 1,616원** |
| **자동으로 멈추는 한도** | | **$3.00 (약 4,200원)** |

실제로 돌려 보니 **제가 잡았던 값의 절반 이하**였습니다
(넣는 자료 양을 넉넉하게 잡았는데 실제로는 그만큼 안 들었습니다).
한도는 그대로 둡니다 — 순위 변동이 큰 날은 자료가 늘어 비용도 올라갑니다.

**한도를 넘길 수 없습니다.** 프로그램이 매번 "이번 달에 얼마 썼나" 를 먼저
세고, `$3.00` 에 닿으면 **그 달 남은 날은 아예 부르지 않습니다.**
"조금만 더" 가 없습니다.

한도는 `config/report.yaml` 의 `monthly_cap_usd` 한 줄입니다.
값이 싼 AI 로 바꾸고 싶으시면 같은 파일의 `model` 을
`claude-haiku-4-5` 로 바꾸시면 값이 **1/5** 로 줄어듭니다 (글은 단순해집니다).

> 작업 기록에 매번 "이번 1건 비용 / 이번 달 합계" 가 찍히고, 표에도 남습니다.
> 사이트 [리포트] 화면 아래에서도 이번 달 쓴 돈을 보실 수 있습니다.

### 지난 7일치를 같이 보는 값 (2026-08-12 추가)

지난 리포트를 함께 읽히면 그만큼 **넣는 글이 길어져 값이 오릅니다.**

| | |
|---|---|
| 지난 7편 글자수 | 약 4,000자 |
| 하루 추가 | **약 28원** |
| 한 달(31일) 추가 | **약 850원** |
| 합쳐서 한 달 | 약 1,616원 + 850원 = **약 2,470원** (한도 4,200원 안) |

⚠️ 그래도 한도가 빠듯해지면 프로그램이 **스스로 날수를 줄이고 그 사실을
작업 기록에 적습니다.** 조용히 줄이지 않습니다.

```
지난 리포트 7편을 같이 봅니다 (2026-08-05 ~ 2026-08-11)
  · 이것 때문에 늘어나는 값: 하루 약 $0.0197 (약 28원) · 남은 20일이면 약 $0.39
```

며칠치를 볼지는 `config/report.yaml` 의 `history_days` 한 줄입니다.
`0` 으로 두면 지난 리포트를 아예 안 봅니다(예전 방식).

## 나) 하실 일 — 3분

### 나-1. Anthropic 계정 만들기 (1분)

1. <https://console.anthropic.com> 접속 → 구글 계정 등으로 가입
2. 가입만으로는 돈이 나가지 않습니다

### 나-2. 돈 채우기 (1분)

Anthropic 은 **미리 채워 두는 방식**입니다. 자동으로 계속 빠져나가지 않습니다.

1. 왼쪽 **Billing** → **Add credits**
2. **$5** 를 채우시면 됩니다 (약 7,000원 · 두 달치)
3. **Auto-reload 는 반드시 꺼 두세요.** 켜면 다 쓸 때마다 자동으로
   또 결제됩니다. 끄면 다 쓴 순간 그냥 멈춥니다 — 이쪽이 안전합니다

> 💳 카드 등록이 부담스러우시면 이 기능은 안 켜셔도 됩니다.
> 사이트의 다른 기능은 전부 그대로 돌아갑니다.

### 나-3. 열쇠 만들기 (30초)

1. 왼쪽 **API Keys** → **Create Key**
2. 이름은 `bestseller` 같은 걸로
3. `sk-ant-...` 로 시작하는 긴 글자가 뜹니다.
   **이 화면을 닫으면 다시 못 봅니다.** 바로 복사하세요

### 나-4. GitHub 금고에 넣기 (30초)

1. <https://github.com/choimog/apple/settings/secrets/actions> 접속
2. **New repository secret**
3. Name: `ANTHROPIC_API_KEY` / Secret: 방금 복사한 `sk-ant-...`
4. **Add secret**

> 열쇠는 **오직 여기에만** 둡니다. 코드에는 한 줄도 없습니다.

## 다) 확인 (1분)

1. <https://github.com/choimog/apple/actions/workflows/report.yml> 접속
2. **Run workflow** → 초록 **Run workflow**
3. 1~2분 뒤 초록 체크(✅)가 뜨면 성공
4. 작업 기록을 열면 이렇게 찍혀 있습니다

   ```
   이번 달: 0건 · $0.0000 (약 0원) / 한도 $3.00 (약 4,200원)
   기준 날짜: 2026-08-09
     종합 40권 · 신규 0 · 상승 4 · 하락 0
   claude-opus-5 에게 요약을 부탁합니다...
     넣은 토큰 3,624 · 나온 토큰 765
     이번 1건 비용: $0.0372 (약 52원)
     이 속도면 한 달에 $1.15 (약 1,616원) 정도입니다.
   ```

   (위는 2026-08-09 첫 실행의 **실제** 기록입니다)

5. 사이트 위쪽 **[리포트]** 메뉴에서 읽으실 수 있습니다
6. 홈에 들어가시면 **하루 한 번 창으로도** 뜹니다 (닫으면 그날은 안 뜹니다)

이후로는 **매일 아침, 수집·매칭이 끝나는 즉시** 저절로 만들어집니다.
보통 한국시간 **7시 30분 전후**입니다.
(사슬이 안 걸린 날을 대비해 10시 30분 예약도 보험으로 남겨 두었습니다)

## 마) 지어내지 않게 막아 둔 것

AI 는 자료가 없으면 **그럴듯하게 지어내는** 성질이 있습니다.
대표님이 처음에 못 박으신 **"가짜 데이터로 된 것처럼 보이게 하지 마"** 를
지키기 위해 이렇게 막아 두었습니다.

- AI 에게는 **순위 자료만** 줍니다. 판매 부수·광고·언론 보도 같은 건
  자료에 없으니 "추측하지 마라" 고 못 박아 둡니다
- **어제 자료가 없으면** AI 에게 "변화에 대해 아무 말도 하지 마라" 고 알립니다
  (안 그러면 첫날 40권 전부가 '신규 진입' 이 됩니다)
- 순위 변화는 AI 가 아니라 **프로그램이 직접 계산**해서 넘깁니다
- AI 가 빈 글을 돌려주거나 거절하면 **저장하지 않고 실패로 알립니다**
- 이것들이 지켜지는지 `tests/test_report.py` 가 매번 확인합니다
  (AI 를 부르기 전에 확인하므로 시험은 돈을 쓰지 않습니다)
- 깔린 라이브러리가 우리가 보내는 설정을 **실제로 받아주는지**도 확인합니다
  (2026-08-09 에 이 확인이 없어서 첫 실행이 실패했습니다. 그때 잡았습니다)

### 🚨 지난 리포트를 같이 읽힐 때 특히 조심한 것 (2026-08-12)

지난 리포트에는 **며칠 전 순위와 숫자**가 적혀 있습니다. 그것을 오늘
것처럼 옮겨 적으면 리포트가 **거짓말**을 하게 됩니다. 그래서

- 오늘 자료를 **앞에**, 지난 리포트를 **뒤에** 붙입니다.
  (지난 글이 앞에 오면 거기에 끌려가 오늘 없는 책 이야기를 이어 씁니다)
- 지난 글에는 "**이건 자료가 아닙니다. 여기 적힌 책·숫자를 오늘 것으로
  쓰지 마세요**" 라고 이름표를 붙여 넘깁니다
- 긴 리포트를 자를 때는 **잘랐다고 적어 둡니다.** 조용히 자르면 AI 가
  "뒤에 아무 말도 없었다" 고 믿습니다
- `tests/test_report_history.py` 가 이것들을 매번 확인합니다
