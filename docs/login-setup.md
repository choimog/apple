작성 2026-08-09

**【대표님 결정】** "비상업적으로 친구들한테만 회원 형식으로 공유하려고 하는 거야."

사이트를 **로그인한 사람만** 볼 수 있게 만들어 두었습니다.
아래 4가지를 해주시면 켜집니다.

> ⚠️ **차례를 지켜 주세요.** ①을 건너뛰고 ③을 먼저 하시면
> 대표님도 사이트에 못 들어가십니다. (자료가 사라지진 않습니다)

**하나만 잠그면 잠근 척이 됩니다.**

# ① 가입 신청을 막습니다 (2분)

이걸 안 하면 **주소를 아는 누구나 스스로 회원이 됩니다.** 회원제가 아니게 됩니다.

1. https://supabase.com/dashboard → 우리 프로젝트
2. 왼쪽 **Authentication** → **Sign In / Providers**
3. **Email** 을 펼칩니다
4. **Allow new users to sign up** 을 **끕니다(OFF)**
5. **Confirm email** 도 **끕니다(OFF)**
   > 왜 끄나요: 켜 두면 계정을 만들 때마다 확인 메일이 나갑니다.
   > 무료 요금제는 보낼 수 있는 메일이 시간당 몇 통뿐이라, 친구 여러 분을
   > 한 번에 등록하면 뒤에 오신 분은 메일을 못 받고 못 들어옵니다.
   > 계정은 대표님이 직접 만들어 주시므로 확인 절차가 필요 없습니다.
6. **Save**

# ③ 데이터베이스를 잠급니다 (1분)

**②를 먼저 하셨는지 확인하고 진행해 주세요.**

1. Supabase → 왼쪽 **SQL Editor** → **New query**
2. 저장소의 [`db/auth.sql`](../db/auth.sql) **전체**를 복사해서 붙여넣기
3. **Run**

**확인:** 맨 아래에 이런 표가 5줄 나옵니다.
**판정 칸이 전부 ✅ 면 끝난 것입니다.**

| 번호 | 확인 항목 | 결과 | 판정 |
|---|---|---|---|
| 1 | 로그인 없이 보이는 표 | 0개 | ✅ 잘 잠겼습니다 |
| 2 | 잠금이 꺼진 표 | 0개 | ✅ 전부 켜져 있습니다 |
| 3 | 회원이 볼 수 있는 표 | 11 / 11개 | ✅ 회원은 다 볼 수 있습니다 |
| 4 | 검토 화면 쓰기 권한 | 3 / 3칸 | ✅ 버튼이 동작합니다 |
| 5 | 관리자 계정 | 1명 | ✅ 매칭 검토 메뉴가 보입니다 |

> 💡 Supabase 는 **맨 마지막 조회 결과만** 보여줍니다.
> 그래서 확인할 것을 이 한 표에 모아 두었습니다.

> ⚠️ 매일 수집은 영향을 받지 않습니다. 크롤러는 '관리자 열쇠' 로 접속하는데,
> 이 열쇠는 잠금을 통과합니다.

> ※ 여러 번 실행해도 안전합니다. 자료는 하나도 안 바뀝니다.

# ④ 들어가 봅니다 (1분)

1. 사이트 주소를 엽니다 → **로그인 화면**이 떠야 정상입니다
2. ②에서 만든 이메일·비밀번호로 로그인
3. 평소처럼 순위가 보이면 끝입니다

**안 되면:**

| 화면에 뜨는 말 | 뜻 · 할 일 |
|---|---|
| 이메일이나 비밀번호가 맞지 않습니다 | 오타이거나, ②에서 **Auto Confirm User** 를 안 켠 경우 |
| 계정이 아직 확인되지 않았습니다 | Authentication → Users → 그 계정 → 확인 처리 |
| 데이터를 불러오지 못했습니다 | ③을 실행했는지 확인 (회원_읽기가 1이어야 합니다) |

## ④ 다음 — [매칭 검토] 화면 (관리자에게만 보입니다)

로그인하시면 위쪽 메뉴에 **[매칭 검토]** 가 생깁니다.
서점마다 표기가 달라서 기계가 "같은 책인지" 확신하지 못한 짝을
대표님이 직접 정해 주는 화면입니다.

| 탭 | 무엇 |
|---|---|
| **검토 대기** | 애매해서 일단 묶어 둔 짝. 여기부터 보시면 됩니다 |
| **자동으로 묶은 것** | 확신해서 묶은 짝. **잘못 묶인 것을 여기서 떼어냅니다** |
| **내가 내린 결정** | 누르신 것. 되돌릴 수 있습니다 |

- 대표님이 누르신 결정은 **기계가 절대 못 뒤집습니다.**
- 다만 순위 화면에 반영되는 것은 **다음 날 아침**입니다.
