개인이 쓰려고 만든 도구입니다. **외부 사용·복제·재배포를 허용하지 않습니다**
→ [LICENSE](./LICENSE)

---

## 👉 운영하시는 분은 여기부터

**[HANDOVER.md](./HANDOVER.md)** 하나로 운영이 되도록 썼습니다.
문제가 생겼을 때 무엇을 하면 되는지, 계정은 어떻게 추가하는지 —
**개발 지식이 없어도 됩니다.**

| 알고 싶은 것 | 어디를 보면 되나 |
|---|---|
| 🚨 문제가 생겼다 · 매일 하는 일 | [HANDOVER.md](./HANDOVER.md) |
| 화면 쓰는 법 · 숫자 읽는 법 | [docs/site-guide.md](docs/site-guide.md) |
| 지켜야 하는 원칙 | [HANDOVER.md 6번](./HANDOVER.md#6-절대-지키고-있는-원칙) |
| 어느 폴더에 뭐가 있나 | [HANDOVER.md 9번](./HANDOVER.md#9-파일-지도) |
| 설치·배포 | [docs/deploy.md](docs/deploy.md) |
| 데이터베이스 SQL 파일 설명 | [db/README.md](db/README.md) |

> 설정을 고치실 일은 대부분 `config/` 폴더 안입니다.
> 무엇을 고치면 되는지는 위 문서에 적혀 있습니다.
