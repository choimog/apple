# 사이트 개편 내역 (2026-08-08)

대표님 지적 사항과, 그걸 고치면서 함께 손본 것들을 전부 적었습니다.
번호는 확인하실 때 쓰시라고 붙였습니다.

---

## A. 지적하신 5가지

| # | 지적 | 고친 내용 |
|---|---|---|
| 1 | 디자인이 옛날 느낌 | 색·글자·간격 기준을 새로 정하고 모든 화면을 그 위에 다시 올림 |
| 2 | 검색하면 한 책이 3사로 쪼개짐 | 묶인 책 기준 **한 줄**로 표시, 서점은 배지로 |
| 3 | 수집 상태에 분이 없음 | 서점별 **시작·종료 시각(분)** + 걸린 시간 표 |
| 4 | 분야 순위인지 전체 순위인지 불분명 | 모든 순위 화면 위에 **범위 안내 띠** 추가 |
| 5 | 올라있는 분야가 뒤섞임 | 서점별로 묶고 **전체 순위 / 분야 순위**를 나눔 |

## B. 디자인 기조 (1~18)

1. 색을 '역할 이름'으로 바꿈 — `bg-surface`, `text-ink` 처럼. 색값은 한 파일에만 존재
2. **어두운 화면(다크 모드) 지원** — 기기 설정을 따라 자동 전환
3. 배경을 차가운 회색 → 따뜻한 톤(#faf9f7)으로. 출판 자료에 어울리는 색감
4. 카드 모서리 8px → 16px, 그림자를 아주 옅게 (납작하고 정돈된 느낌)
5. 제목 글자에 자간 -0.02em 적용 — 한글 제목이 뭉치지 않고 또렷해짐
6. 본문/보조/흐림 3단계 글자색 체계 확립
7. 숫자에 고정폭(tabular) 적용 — 표에서 자릿수가 흔들리지 않음
8. 화면마다 제각각이던 카드·여백·글자 크기를 공통 조각으로 통일
9. 모든 화면 맨 위에 '분류(eyebrow) → 제목 → 설명' 3단 구조 도입
10. 강조색을 남색 계열로 통일 (서점 색과 겹치지 않게)
11. 표지 자리표시자를 사선 무늬로 교체 — 이미지 로딩 실패가 티 안 나게
12. 서점 배지를 투명도 기반으로 — 밝은 화면·어두운 화면 모두에서 읽힘
13. 서점 색을 **색약 검사기로 두 모드 모두 통과** 확인 (ΔE 기준)
14. 색만으로 구분하지 않음 — 서점 배지에 항상 이름을 함께 표기
15. 상단 메뉴를 반투명 + 흐림 효과로 고정 (스크롤해도 길을 잃지 않음)
16. 바닥글을 카드 안으로 넣어 본문과 분리
17. 인쇄할 때 메뉴·바닥글이 빠지도록 설정
18. 애니메이션을 줄이는 설정을 쓰는 분에겐 전환 효과를 끔

## C. 길찾기 · 구조 (19~34)

19. 메뉴를 **순위 / 분석** 두 덩어리로 분리
20. 지금 보고 있는 메뉴에 **밑줄 표시** (예전엔 어디 있는지 알 수 없었음)
21. 첫 화면을 '대시보드'로 — 요약·TOP10·출판사·저자·분야를 한눈에
22. 종합 순위를 `/best` 로 독립 (첫 화면과 역할 분리)
23. 서점별 순위를 `/store` 로 독립
24. 출판사 순위 `/publishers`, 저자 순위 `/authors` 신설
25. 분야 분석 `/insights` 신설
26. 출판사 상세 `/publisher/{이름}`, 저자 상세 `/author/{이름}` 신설
27. 화면마다 브라우저 탭 제목이 다르게 (예전엔 전부 같았음)
28. 키보드 사용자를 위한 '본문으로 건너뛰기' 링크
29. 메뉴에 `aria-current` 부여 — 화면 낭독기가 현재 위치를 읽어줌
30. 서점별 화면의 선택 순서를 **1 서점 → 2 기간 → 3 분야** 로 번호 표시
31. 서점을 바꾸면 분야·기간이 초기화되어 엉뚱한 조합이 안 생김
32. 대시보드 각 카드에서 해당 전체 화면으로 가는 링크
33. 종합↔서점별 화면이 서로를 안내 (역할 차이를 설명하며)
34. 도서 상세에서 저자·출판사를 눌러 그들의 책 목록으로 이동

## D. 일간 / 주간 구분 (35~42)

35. 작은 알약 → **설명이 붙은 큰 전환 스위치**
36. 일간은 하늘색, 주간은 보라색으로 색 자체를 분리
37. 선택된 쪽 글자색까지 그 색으로 (선택 상태가 확실히 보임)
38. 순위표 제목에 기간 배지 상시 표시
39. 배지에 뜻을 함께 표기 — "주간 · 최근 7일 누적"
40. 도서 상세의 3사 카드에서 일간/주간을 각각 표시
41. 추이 그래프를 일간·주간으로 분리
42. 내려받는 파일 이름에도 기간 포함

## E. "무슨 순위인가" 명확화 (43~52)

43. **범위 안내 띠 신설** — `3사 종합 › 일간 › 전체 › 8월 8일`
44. 전체(종합)일 때: "분야를 가리지 않은 종합 순위입니다"
45. 특정 분야일 때: "'소설' 분야 안에서의 순위입니다. 전체 순위와는 다릅니다"
46. 서점별 화면: "교보문고가 발표한 '전체' 순위입니다"
47. 매장 순위: "그 매장에서 어제 하루 팔린 순서입니다"
48. 종합 순위표에 "각 서점 300위까지 봄" 명시
49. 출판사·저자 상세의 번호가 **그 목록 안의 차례**임을 명시
50. 도서 상세: '전체 순위'와 '분야 안에서의 순위'를 시각적으로 분리
51. 각 순위 숫자에 마우스를 올리면 "교보문고 소설 · 일간 3위" 툴팁
52. 종합 순위 계산 방법을 접이식으로 화면에 그대로 기재

## F. 검색 (53~63)

53. **같은 책은 한 줄** — 3사로 쪼개지지 않음
54. 어느 서점에 있는지 배지로 표시 (없는 서점은 회색)
55. "회색 = 그 서점에서 안 판다는 뜻이 아님" 을 명시
56. 최고 순위·최근 순위 날짜를 함께 표시
57. 검색어 예시 버튼 4개 (뭘 검색해야 할지 막막하지 않게)
58. 검색창을 `type="search"` 로 — 모바일에서 지우기 버튼이 생김
59. 자동완성 끔 (엉뚱한 값이 채워지지 않게)
60. 결과 50건 넘으면 "더 좁혀 보세요" 안내
61. 결과 없을 때 다음에 뭘 해볼지 안내 (띄어쓰기 등)
62. 저자·출판사를 눌러 바로 그 목록으로 이동
63. 검색 결과에서도 표지·제목·저자·출판사 배치를 목록과 동일하게

## G. 수집 상태 (64~74)

64. **시작·종료 시각을 분까지** 표시
65. 한국시간으로 변환해서 표시 (DB 는 세계표준시로 저장)
66. 걸린 시간을 "1시간 10분" 으로 계산해 표시
67. 서점별로 줄을 나눠 어느 서점이 오래 걸리는지 보이게
68. 마지막 수집 요약 4칸 (수집일·끝난 시각·성공/실패·수집량)
69. "3분 전" 같은 상대 시각 병기
70. 날짜를 "8월 8일 (금)" 로 — 요일이 보이면 주간 흐름을 읽기 쉬움
71. 실패 건수를 빨간색으로 강조, 0이면 흐리게
72. 실패 목록에 사유를 그대로 표시
73. 보관소(R2)로 옮긴 기간을 별도 안내
74. 읽기 권한 문제일 때 `db/rls.sql` 안내

## H. 도서 상세 (75~84)

75. 올라 있는 목록을 **서점별로 묶음**
76. 그 안에서 **전체 순위를 위에 크게**, 분야 순위는 아래에 작게
77. 매장 순위를 별도 카드로 분리 (성격이 다름)
78. 전체/분야 건수를 서점마다 표기
79. 3사 카드에서 순위가 없는 서점은 점선 테두리로 구분
80. ISBN 없을 때 이유를 툴팁으로 설명 (교보만 목록에 노출)
81. 판매지수 이름을 서점별로 정확히 (알라딘은 '세일즈포인트')
82. 판매지수 기록이 하나도 없으면 그래프 자체를 숨김
83. 책을 못 찾았을 때 검색으로 가는 안내
84. 서점별 제목 표기 차이를 목록형으로 정리

## I. 값의 정직성 (85~93)

85. "순위 밖"과 "값 없음"을 구분해 표시
86. 왜 없는지를 툴팁으로 (예: "300위 안에 없습니다")
87. 판매지수를 서점끼리 평균 내지 않음 (계산식이 다른 별개 지표)
88. 교보 판매지수는 '미제공' 으로 명시 (0 으로 채우지 않음)
89. 그래프에서 값이 없는 날은 선을 잇지 않음
90. 수집 안 된 날짜는 목록에 아예 없음 (빈 데이터로 채우지 않음)
91. 종합 순위에서 없는 서점은 평균 계산에서 제외 (가짜 순위 안 넣음)
92. 분야 점유율은 비율이 아니라 '몇 권' — 원그래프를 일부러 안 씀
93. DB 계산 기능이 없을 때 "데이터 없음"이 아니라 "기능을 켜세요" 로 표시

## J. 속도 (94~99)

94. 검색 조회를 14.4초 → **0.4초 이하** (조회 방식·색인 개선)
95. 저자 검색용 색인 추가 (제목·출판사에만 있었음)
96. 분야 점유율 3.9초 → **0.16초** (조회 방향 반대로)
97. 날짜 목록 왕복 40번 → **1번**
98. 종합 순위 6,000줄 전송 → **100줄**
99. 등락 계산에 필요한 만큼만 조회 (1,000줄 → 50줄)

## K. 그 밖 (100~112)

100. 서점 정보(이름·색·판매지수 제공 여부)를 한 파일로 통합
101. 날짜·시각·숫자 표기 함수를 한 파일로 통합
102. 가로로 긴 표는 자기 안에서만 스크롤 (본문이 밀리지 않음)
103. 모바일에서 좌우 스크롤이 생기지 않도록 처리
104. 순위 1·2·3위에 금·은·동 색 배지
105. 목록 항목에 마우스를 올리면 옅게 반응
106. 빈 화면마다 "그래서 뭘 하면 되는지" 안내 추가
107. 접이식 설명 상자에 열림/닫힘 화살표 표시
108. 통계 타일에 보조 설명 줄 추가
109. 막대 목록에 순번 표시
110. 주소창 색을 밝은/어두운 화면에 맞게 설정
111. 사이트 설명문(검색엔진용) 보강
112. 모든 화면을 실제로 열어보는 자동 점검에 검색·상태 화면 추가

## 아직 못 한 것 (정직하게)

- **실제 데이터로 그려진 화면을 제가 눈으로 보지 못했습니다.** 이 작업
  환경에서 실제 Supabase 와 배포 주소가 모두 차단돼 있습니다.
  화면 렌더링은 같은 모양의 가짜 데이터로, 데이터베이스 계산은 진짜
  PostgreSQL(350만 줄)로 나눠서 확인했습니다.
- 어두운 화면(다크 모드)은 기기 설정을 따라갑니다. 사이트 안에서 직접
  바꾸는 버튼은 아직 없습니다.
- 모바일 전용 레이아웃은 '좁아지면 접히는' 수준입니다. 손가락 조작에
  맞춘 별도 화면은 아직 없습니다.
