# 0단계 🤖 교보 주간 분야별 순위 깊이 확인 · 30분

**2026-08-09 감사 중 발견했습니다.**

수집 깊이가 분야마다 다릅니다.

| 묶음 | 분야 수 | 몇 위까지 |
|---|---|---|
| 교보 온라인 일간 | 27 | 1000위 |
| 교보 주간 **전체** | 1 | 1000위 |
| **교보 주간 분야별** | **26** | **20위** ← |
| 교보 매장별 | 37개 매장 | 200위 |
| 예스24 · 알라딘 (일간·주간) | 118 | 1000위 |

대표님이 **"301위에서 1000위 구간을 볼 일이 있다"** 고 하셨는데,
교보 주간 분야별에서는 그 구간이 아예 없습니다.

**두 가지 중 하나입니다. 확인해야 압니다.**

- 교보가 주간 분야별은 20개만 보여준다 → 어쩔 수 없습니다
- 제가 주소에 `&per=200` 을 안 붙였다 → 제 실수입니다. 고칠 수 있습니다

**⚠️ 고칠 수 있더라도 용량을 먼저 봐야 합니다.**
26개 분야를 20위 → 1000위로 올리면 하루 약 2만 5천 줄이 더 쌓입니다.

```
지금  예상 최대 약 456MB / 500MB
올리면 예상 최대 약 525MB / 500MB   ← 넘칩니다
```

그래서 고칠 수 있다고 바로 고치지 않습니다. 확인한 뒤,
넘친다면 대표님께 선택지를 드리겠습니다
(보관 기간 단축 / 일부 분야만 / Supabase Pro).

| | 지금 |
