# 구글 시트 자동 내보내기 — 켜는 법

매일 아침 10시에 순위표가 **구글 시트에 저절로 쌓이게** 만듭니다.
사이트에서 [엑셀로 받기] 를 누르지 않아도 됩니다.

**대표님이 하실 일: 약 10분.** 아래 다-1 ~ 다-5 를 순서대로만 하시면 됩니다.
**돈은 들지 않습니다.** 구글 계정만 있으면 됩니다.

> 켜지 않으셔도 사이트는 그대로 돌아갑니다.
> 설정이 없으면 이 작업은 "할 일이 없습니다" 하고 조용히 넘어갑니다.

---

## 무엇이 쌓이나요?

`config/sheets.yaml` 에 적어 둔 표가 **탭 하나씩** 만들어집니다. 지금은 셋입니다.

| 탭 이름 | 내용 |
|---|---|
| 종합 일간 TOP100 | 2개 서점 이상에 오른 책, 일간 100위까지 |
| 종합 주간 TOP100 | 같은 것의 주간판 |
| 알라딘 일간 전체 TOP100 | 알라딘 온라인 일간 전체 100위까지 |

칸은 이렇게 들어갑니다.

```
날짜 | 구분 | 순위 | 제목 | 저자 | 출판사 | 출간월 | 판매지수 | 서점
```

**덮어쓰지 않고 아래에 쌓습니다.** 그래서 시트에서 바로 "이 책이 며칠 만에
몇 위 올랐나" 를 볼 수 있습니다. 180일치가 넘으면 오래된 줄부터 지웁니다
(구글 시트의 칸 한도 때문입니다. `config/sheets.yaml` 의 `keep_days`).

---

## 가) 왜 이런 절차가 필요한가요?

구글 시트는 대표님 것이라 **아무나 못 씁니다.** 그래서 이 프로그램에게
**"로봇 계정"** 을 하나 만들어 주고, 그 로봇에게만 이 시트를 열어 줍니다.

- 로봇 계정 = **서비스 계정(service account)** — 사람이 아니라 프로그램이 쓰는 구글 계정
- 로봇의 신분증 = **JSON 열쇠 파일** — 이걸 GitHub 금고에 넣습니다

로봇에게는 **대표님이 공유해 준 시트 하나만** 보입니다.
구글 드라이브의 다른 파일은 못 봅니다.

---

## 나) 미리 준비 — 빈 구글 시트 하나

1. <https://sheets.google.com> 접속 → **빈 스프레드시트** 만들기
2. 이름을 아무거나 지으세요 (예: `베스트셀러 자동기록`)
3. 주소창을 보면 이렇게 생겼습니다

   ```
   https://docs.google.com/spreadsheets/d/1AbCdEfGhIjKlMnOpQrStUvWxYz1234567890/edit
                                          └─────────── 이 부분이 시트 ID ───────────┘
   ```

4. **가운데 긴 글자를 복사해서 메모장에 붙여 두세요.** 다-5 에서 씁니다.

---

## 다) 로봇 계정 만들기

### 다-1. 구글 클라우드 프로젝트 만들기 (2분)

1. <https://console.cloud.google.com/projectcreate> 접속
2. **프로젝트 이름**: `bestseller` (아무거나 괜찮습니다)
3. **만들기** 클릭 → 30초쯤 기다리면 만들어집니다

> 신용카드를 물어보지 않습니다. 물어본다면 잘못 들어가신 겁니다
> (여기는 `console.cloud.google.com` 이어야 합니다).

### 다-2. 시트 기능 켜기 (1분)

1. <https://console.cloud.google.com/apis/library/sheets.googleapis.com> 접속
2. 화면 위에서 방금 만든 프로젝트(`bestseller`)가 선택돼 있는지 확인
3. **사용 (Enable)** 파란 버튼 클릭

### 다-3. 로봇 계정 만들기 (2분)

1. <https://console.cloud.google.com/iam-admin/serviceaccounts> 접속
2. **+ 서비스 계정 만들기** 클릭
3. **서비스 계정 이름**: `sheet-writer` → **만들고 계속하기**
4. "역할 부여" 와 "사용자 액세스" 는 **아무것도 고르지 말고 건너뛰기**
   → **완료**

   > 역할이 필요 없는 이유: 이 로봇은 구글 클라우드에서 할 일이 없습니다.
   > 시트를 여는 권한은 다-5 에서 **시트를 직접 공유**해서 줍니다.

5. 목록에 `sheet-writer@bestseller-xxxxx.iam.gserviceaccount.com` 같은
   **이메일 주소**가 보입니다.
   **이것을 복사해서 메모장에 붙여 두세요.** 다-5 에서 씁니다.

### 다-4. 신분증(JSON 파일) 내려받기 (1분)

1. 방금 만든 `sheet-writer` 를 클릭
2. 위쪽 탭에서 **키(KEYS)** 클릭
3. **키 추가 → 새 키 만들기 → JSON** 선택 → **만들기**
4. `.json` 파일이 자동으로 내려받아집니다

> 🚨 이 파일은 **비밀번호와 같습니다.**
> 메일로 보내거나 카톡으로 보내지 마세요. GitHub 금고에만 넣습니다.
> 넣고 나면 PC 에서 지우셔도 됩니다.

### 다-5. 시트를 로봇에게 공유 (1분)

1. 나) 에서 만든 구글 시트를 엽니다
2. 오른쪽 위 **공유** 클릭
3. 다-3 에서 복사한 **로봇 이메일 주소**를 붙여넣기
4. 권한을 **편집자** 로 (뷰어 아님 — 써야 하니까요)
5. "알림 보내기" 체크는 **꺼도** 됩니다 → **보내기**

## 라) GitHub 금고에 넣기 (2분)

> 열쇠는 **오직 여기에만** 둡니다. 코드에는 넣지 않습니다.

1. <https://github.com/choimog/apple/settings/secrets/actions> 접속
2. **New repository secret** 클릭 → 두 개를 차례로 만듭니다

| Name (그대로 대문자로) | Secret (값) |
|---|---|
| `GOOGLE_SERVICE_ACCOUNT_JSON` | 다-4 에서 받은 `.json` 파일을 **메모장으로 열어서, 안에 든 글자 전체**를 복사해 붙여넣기 (`{` 로 시작해 `}` 로 끝납니다) |
| `GOOGLE_SHEET_ID` | 나-4 에서 복사한 **시트 ID** (긴 글자 하나. 주소 전체가 아닙니다) |

> ⚠️ 파일 **이름**이 아니라 파일 **안에 든 내용**입니다.
> `{"type": "service_account", "project_id": ...` 이렇게 시작하면 맞습니다.

## 마) 확인 (1분)

1. <https://github.com/choimog/apple/actions/workflows/export-sheets.yml> 접속
2. 오른쪽 **Run workflow** → 초록 **Run workflow** 클릭
3. 1~2분 뒤 새로고침 → **초록 체크(✅)** 가 뜨면 성공
4. 구글 시트를 열어 보세요. 탭 세 개가 생기고 줄이 채워져 있습니다

이후로는 **매일 아침 10시(한국시간)** 에 저절로 쌓입니다.

## 바) 안 될 때 — 증상별

| 화면에 뜬 말 | 뜻 | 하실 일 |
|---|---|---|
| `구글 접속 정보가 없어 아무것도 하지 않았습니다` | 금고에 열쇠가 없음 | 라) 를 다시 |
| `GOOGLE_SERVICE_ACCOUNT_JSON 이 올바른 형식이 아닙니다` | 파일 이름을 붙여넣으셨을 가능성 | `.json` 을 메모장으로 열어 **내용 전체**를 다시 |
| `시트를 열 권한이 없습니다` | 로봇에게 공유를 안 함 | 다-5 를 다시 (권한은 **편집자**) |
| `그런 시트를 찾을 수 없습니다` | 시트 ID 가 틀림 | 나-4 를 다시 (주소 전체가 아니라 가운데 글자) |
| `그런 분야를 못 찾았습니다` | `config/sheets.yaml` 의 이름이 `config/sources.yaml` 과 다름 | 저(클로드)에게 말씀해 주세요 |
| `이미 2026-08-10 가 있어 건너뜀` | 정상입니다 | 아무것도 안 하셔도 됩니다 (두 번 쌓지 않으려는 것) |
| `그 날짜에 자료가 없어 아무것도 안 씀` | 그날 수집이 안 됐거나 매칭 전 | [수집 상태] 화면을 보세요 |

> **빈 줄을 넣어 "된 것처럼" 보이게 하지 않습니다.**
> 자료가 없으면 안 씁니다. 분야 이름이 틀리면 실패로 알립니다.

## 사) 내보낼 표를 바꾸고 싶으면

`config/sheets.yaml` 을 고치시면 됩니다. 탭 하나가 한 덩어리입니다.

```yaml
  - tab: "예스24 주간 소설 TOP50"   # 시트에 만들어질 탭 이름
    kind: category                  # combined(종합) | category(서점 분야)
    store: yes24                    # kyobo | yes24 | aladin
    category_kind: weekly           # online | weekly | offline
    category: "소설"                # config/sources.yaml 의 이름과 똑같이
    top: 50
```

고치기 어려우시면 **"이 표도 시트에 넣어줘"** 라고 말씀만 주세요.
